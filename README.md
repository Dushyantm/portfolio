# Personal Portfolio

A modern and responsive portfolio website showcasing my projects, skills, and professional experience.

## 🚀 Features

- Modern and clean UI design
- Project showcase with GitHub integration
- Detailed resume/CV section
- Technical skills overview
- Responsive design for all devices

## 🛠️ Built With

- React.js
- Node.js
- CSS3
- React Icons
- TypeWriter Effect

## 🏃‍♂️ Getting Started

1. Clone the repository
```bash
git clone https://github.com/Dushyantm/portfolio.git
```

2. Install dependencies
```bash
npm install
```

3. Start the development server
```bash
npm start
```
The application will open in your default browser at `http://localhost:3000`
